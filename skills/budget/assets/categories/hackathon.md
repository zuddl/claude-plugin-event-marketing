# Hackathon — budget categories

Default structure for a customer or developer hackathon. Prizes and meals dominate.

- Venue (~18%)
  - Location Rental
  - AV Equipment
  - Wi-Fi (high-capacity)
- F&B (~22%)
  - Breakfast
  - Lunch
  - Dinner
  - Snacks & coffee
- Prizes (~25%)
  - Cash prizes
  - Non-cash prizes (hardware, swag bundles)
- Swag (~12%)
  - T-shirts
  - Stickers / smaller items
- AV & rentals (~8%)
  - Stage / lighting
  - Power strips / extension
- Tooling / Credits (~5%)
  - API / cloud credits provisioning
- Photography & Video (~3%)
  - Photographer
- Staffing (~3%)
  - Onsite event manager
  - Mentor compensation (if any)
- Misc / Contingency (~4%)
  - Contingency
