# Ancillary Tradeshow Event — budget categories

Default structure for an event running alongside a major conference (RSA, Black Hat, Dreamforce, AWS re:Invent, KubeCon). Venue + F&B dominate; internal travel becomes a real line.

- Venue (~30%)
  - Location Rental (premium near convention center)
  - AV Equipment
- F&B (~25%)
  - Catering
  - Beverages
- Branded materials & signage (~10%)
  - Signage (tradeshow-themed)
  - Branded take-aways
- Internal team travel (~12%)
  - Flights (internal reps)
  - Hotel block (internal reps)
- Ground transport / rideshare (~6%)
  - Rideshare credits for attendees
  - Shuttle (optional)
- Photography (~3%)
  - Photographer
- Staffing (~4%)
  - Onsite event manager
- Misc / Contingency (~10%)
  - Contingency
