# Field Event — budget categories

Default structure for a field event with content (workshop, breakfast/lunch with speaker, half-day session).

- Venue (~25%)
  - Location Rental (~80% of category)
  - AV Equipment
  - Wi-Fi
- F&B (~25%)
  - Catering
  - Beverages
- Speaker fees / Honoraria (~12%)
  - Speaker honoraria
  - Speaker travel
- Swag & Gifts (~10%)
  - Branded swag
  - Speaker gift
- Décor & Print (~5%)
  - Signage
  - Printed handouts / agendas
- Photography (~3%)
  - Photographer
- Transportation (~3%)
  - Rideshare credits
- Staffing (~4%)
  - Onsite event manager
- Misc / Contingency (~13%)
  - Contingency
